## Run Locally

```bash
git clone https://github.com/tahsan410/tahsan-portfolio.git
cd tahsan-portfolio
npm install
npm run dev
```

The development server will start at:

```text
http://localhost:5173
```

## Build for Production

```bash
npm run build
npm run preview
```

## Deployment

The portfolio is deployed using **Netlify**.

Build command:

```text
npm run build
```

Output directory:

```text
dist
```
